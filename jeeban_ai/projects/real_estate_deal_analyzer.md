# Real Estate Deal Analyzer

A Streamlit-based AI/data application focused on analyzing real-estate opportunities.

**Technologies:**
- Python
- Streamlit
- MongoDB
- LLaMA 3
- Ollama
- Data processing
- ROI calculation
- Real-estate data
- Web scraping

**Purpose:**
Analyze property information and help evaluate potential real-estate deals using data and local LLM capabilities.
