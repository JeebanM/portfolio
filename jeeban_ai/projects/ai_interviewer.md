# AI Technical Interviewer & Voice Evaluation System

A larger AI recruitment/interview platform combining:
- Generative AI
- Multi-Agent AI
- RAG
- Speech AI
- FastAPI
- React
- PostgreSQL

**Major components:**
Interview Planner → Question Generator → Voice Engine → Speech / Transcript Engine → Answer Evaluation → Code Evaluation → RAG → Evaluation Aggregator → Recruiter Dashboard

The goal is to create an end-to-end AI-powered technical interview and evaluation system.
