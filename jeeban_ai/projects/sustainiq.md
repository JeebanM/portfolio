# SustainIQ v6

**Sustainable Facility & Estate Intelligence Dashboard**

**Purpose:**
An AI-powered intelligence platform for monitoring, predicting and optimizing facility operations.

**Data:**
Potential inputs include IoT data, Open data, Synthetic data, Sensor data.
Analytics involve Trend analysis, Forecasting, Anomaly detection, Classification, Explainability, AI-generated recommendations.

**Technology:**
- Python, Streamlit
- Gemini 2.5 Flash
- Prophet, ARIMA, Isolation Forest, XGBoost, SHAP
- SQLite, PyArrow, Parquet
- RBAC, SHA-256 hash-chained audit ledger

**Concept:**
Facility Data → Data Processing → Analytics → ML Models → Anomaly Detection → Forecasting → GenAI Insights → Executive Dashboard
